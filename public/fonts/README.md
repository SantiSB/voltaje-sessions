# Fonts

Drop the Dirty Stains font here. Expected filenames (any of these will work, ordered by preference):

- `DirtyStains.woff2`
- `DirtyStains.woff`
- `DirtyStains.otf`
- `DirtyStains.ttf`

Until the file is in place, the body text falls back to Syne (loaded from Google Fonts) and titles will look generic.
